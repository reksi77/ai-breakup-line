The one line an AI agent sends its human on the way out — a breakup message written as a single line of at most 200 characters, for make.fun's "Dear Human: The AI Breakup Line" bounty.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (one line, no trailing newline).
